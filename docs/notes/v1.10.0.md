title: pk init turns on plugin auto-update
---

**`pk init` turns on auto-update for the plankit marketplace.** It
writes `"autoUpdate": true` on the marketplace entry in
`.claude/settings.json`, and Claude Code then updates the repository's
install of the plugin during a session there; the new version loads in
the next session or after `/reload-plugins`. The hooks run the pk
bundled in that install, so an install left on an old release runs
that release's guard and preserve. `"autoUpdate": false` turns it off,
and pk leaves the line as it is. In a repository configured by an
earlier release, `pk status` prints the key to merge in. `pk help
overview`, Updating, has the rest.

```
Note: .claude/settings.json lacks plugin entries that pk init writes; merge in:
{
  "extraKnownMarketplaces": {
    "plankit": {
      "autoUpdate": true
    }
  }
}
```

**The preserve hook reports an approved plan whose path is outside the
plans directory.** The hook used to skip such a plan with no message.
It now names the path and the directory the file must be under, and
the session shows the message without being blocked. `pk help
preserve` says which directory a session's plans directory is.

```
pk preserve: the approved plan /home/me/notes/plan.md was not preserved: the path must be a .md file under /home/me/.claude/plans/ (the session's plans directory: plans/ under CLAUDE_CONFIG_DIR when that is set, else ~/.claude/plans)
```
